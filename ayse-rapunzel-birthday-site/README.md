# Ayşe Rapunzel Doğum Günü Sitesi

Bu klasör GitHub Pages uyumlu statik sitedir. `index.html` dosyasını tarayıcıda açman yeterli.

- Şifre: `1010`
- Doğum günü tarihi: `script.js` içindeki `BIRTHDAY`
- Birlikte geçen gün başlangıcı: `script.js` içindeki `TOGETHER_SINCE`
- Fotoğraflar: `assets/photos/photo-1.jpg` ile `photo-6.jpg` arasına görsellerini koy
- Kendi müziğin: `assets/music/ayse.mp3` ekleyip `script.js` içindeki `CUSTOM_MUSIC_FILE` değerini `"assets/music/ayse.mp3"` yap

GitHub Pages için bu klasörün içeriğini bir repo ana dizinine koyup Pages ayarlarında `main` branch ve `/root` seçebilirsin.
